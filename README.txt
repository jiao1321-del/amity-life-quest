AMITY LIFE QUEST 私人 PWA V0.1

包含：五頁介面、任務建立與完成、XP/屬性、做二休二、休息模式、66天紀錄、Amity情境台詞、IndexedDB儲存、JSON備份。

重要：ZIP 不能直接在 iPhone 檔案 App 點開當成 PWA 安裝。需將整個資料夾部署到 HTTPS 靜態網站（例如 GitHub Pages / Cloudflare Pages），以 Safari 開啟 HTTPS 網址，分享 → 加入主畫面。

本版本沒有後端帳號或雲端同步；部署網址如公開，其他人也可能打開介面，但各自本機資料不會因此公開。不要把備份 JSON 上傳到公開網站。
